## Sobre o projeto

Encontrar alguém para praticar um esporte pode ser difícil quando amigos, horários e disponibilidade não coincidem. O MatchPoint surge como uma proposta para facilitar essa conexão.

A ideia é permitir que pessoas encontrem parceiros para praticar esportes de acordo com seus interesses, aproximando quem deseja realizar atividades esportivas em conjunto.

Inspirado na dinâmica de aplicativos de relacionamento, o MatchPoint adapta a ideia de combinar pessoas para um objetivo diferente: **encontrar companhia para praticar esportes**.

Atualmente, o projeto está na fase de prototipação e desenvolvimento.
